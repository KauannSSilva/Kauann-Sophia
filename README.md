# Kauann & Sophia · 1 ano

Site de presente de 1 ano juntos. HTML, CSS e JavaScript puros, sem instalação.

## Como editar

- **Textos, datas, motivos, carta, música:** tudo em `conteudo.js`.
- **Fotos:** coloque na pasta `fotos/` (veja `fotos/LEIA-ME.md`).

## Ver no computador

Abra `index.html` no navegador.

## Publicar (GitHub Pages, grátis)

Settings → Pages → *Deploy from a branch* → escolha a branch e a pasta `/ (root)` → Save.
O endereço fica `https://kauannssilva.github.io/kauann-sophia/`.
